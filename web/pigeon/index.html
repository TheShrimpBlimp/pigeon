Local use, offline operation, and device transfers

Use Chrome or Edge on macOS, Windows, or Linux for USB MIDI transfers. Grant MIDI/SysEx access when connecting. Select matching FM1 input and output ports. Stop playback and release keys before a transfer.

Wait for “Offline ready” before disconnecting Wi-Fi. Every runtime dependency is bundled here. The open page keeps working without a server; its cached address can also reopen offline while the browser retains site data. Browser storage can be cleared or evicted, so download your banks and backups.

Back up full session is a separate action. Sending samples does not require a backup. A recovery backup is saved before restoring. Transfers write device flash; keep USB connected until verification finishes. Session restore commits objects separately and is not atomic. Sample replacement resets settings belonging to the changed audio.

Supported imports include WAV and MP3, plus formats your browser can decode. Songs become indexed mono MP3 at 22.05 kHz; drums become IMA ADPCM. Normalization follows the command-line tool. No audio or session data is sent to a server.

This tool manages sample banks and sessions; it does not flash firmware. Encoder source and licenses.
